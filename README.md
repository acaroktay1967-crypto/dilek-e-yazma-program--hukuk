# ⚖️ Dilekçe Yazma Programı

iPhone dahil tüm cihazlarda çalışan, build gerektirmeyen dilekçe hazırlama uygulaması.

## 🚀 Kullanım

`index.html` dosyasını tarayıcıda açın. Herhangi bir kurulum gerekmez.

### iPhone'da Ana Ekrana Ekleme
1. Safari'de `index.html` dosyasını açın
2. Paylaş butonuna (□↑) dokunun
3. **"Ana Ekrana Ekle"** seçin

## 📋 Özellikler

- 8 hazır hukuki şablon (Mahkeme, SGK, Belediye, Tapu vb.)
- Bilgi formu ile otomatik dilekçe oluşturma
- Yazdırma / PDF kaydetme
- Metin kopyalama ve paylaşma
- iPhone uyumlu mobil tasarım

## ⚠️ Yasal Uyarı

Bu uygulama genel bilgi amaçlıdır; hukuki tavsiye niteliği taşımaz.
