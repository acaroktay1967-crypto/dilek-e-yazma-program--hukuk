# Hukuk Pro iPhone

Bu paket, Windows Electron uygulamasindan cikarilan iPhone uyumlu web/PWA surumudur.

## Kullanım

1. `index.html` dosyasini Safari ile acin.
2. Paylas menusunden **Ana Ekrana Ekle** secenegini kullanin.
3. Uygulama ana ekrandan acildiginda dilekce, karar taslagi ve hesaplama modulleri calisir.

## Notlar

- Windows `.exe` dosyalari iPhone'da calismaz; bu paket tarayici/PWA olarak calisir.
- Kayitlar iPhone Safari yerel hafizasinda tutulur.
- Yazdir/PDF icin iOS paylas veya yazdir menusu kullanilir.
